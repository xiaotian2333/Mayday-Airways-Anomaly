# 快速上手

## 第一次启动

1. 按[安装与启动](installation.md)部署运行包并选择游戏目录。
2. 选择 **启动并附加**，等待游戏进入主界面。
3. 按 `Insert` 打开覆盖层；如果键盘没有 `Insert`，打开游戏暂停菜单并点击「Anomaly」。

覆盖层展开时，鼠标和键盘只控制覆盖层，不会传给游戏。关闭覆盖层后输入恢复到游戏。

## 界面

| 页面 | 用途 |
| --- | --- |
| **Plugins** | 启停、重载、查看内建和第三方插件 |
| **Diagnostics** | Runtime 状态、服务、日志与开发者信息 |
| **Settings** | 切换键、语言、主题和插件源 |

## 启用内建插件

1. 打开覆盖层，进入 **Plugins**。
2. 找到 `Money` 或 `Freecam`。
3. 启用后点击插件行进入窗口。

Money 会显示当前金币和债务；Freecam 需要先在游戏中进入一局，再点击开启。

## 关闭覆盖层

- 再按一次 `Insert`，或点击界面右上角的关闭按钮。
- 如果开启了「记住上次页面」，下次会恢复到同一个页面。

## 遇到问题

覆盖层不出现、插件不加载或游戏崩溃时，先看[故障排查](troubleshooting.md)。
