# 首次使用须知

欢迎使用 Mayday Loader，请先花一分钟读完下面的说明；在你勾选同意之前，插件功能保持锁定。

Mayday Loader 是免费开源软件，如果你是付费获取，那么恭喜你，你被骗了 : (

> [!CAUTION]
>
> 本工具会读写游戏进程内存、安装 Hook 并修改运行时状态，可能导致游戏崩溃、存档损坏或账号受到处罚。
>
> 请在遵守游戏服务条款和当地法律的前提下使用，并自行承担由此带来的全部风险。

## 反馈

- 遇到问题时，请先通过项目仓库的 Issue 反馈，并附上诊断页导出的日志。
- 提交日志、dump 或诊断包前，请先检查并删除其中的敏感信息。

## 数据与隐私

Mayday Loader 默认启用基础使用统计，仅用于匿名统计软件日活和各插件每日使用人数，不上传任何日志文件。

## 遇到问题

- 出现崩溃时，先在 **诊断** 页导出日志再反馈，这样才定位得到是哪一步出的问题。
